# 戴夫适配版 v1.4.8.14-dave.1

本版将潜水员戴夫的离线初始化流程接入 Steam 库原来的“开始游戏”按钮。在启动选项中加入 `-offline` 后，点击开始游戏会自动等待 Steam 离线、启动戴夫，确认本轮 DLC 检查和标题初始化完成，再恢复 Steam 在线。好友看到的游戏状态由 Steam 自己更新，不需要另开快捷方式或手动切换模式。

这是 Windows x64 的 Release 构建，关闭 OpenSteamTool 核心的 Debug 日志。后台组件仍保留判断初始化完成所需的游戏会话日志和简要运行记录。

下载 **`OpenSteamTool-v1.4.8.14-dave.1-Release-x64.zip`**。请选择 Release 下的这个压缩包；GitHub 自动生成的 `Source code` 是源码，不是可运行文件。

## 安装与更新

1. 完全退出 Steam、戴夫及其它 Steam 应用。
2. 更新前备份 Steam 根目录中原有的 `OpenSteamTool.dll`、`dwmapi.dll`、`xinput1_4.dll` 和 `dave-launcher` 文件夹。Steam 根目录是 `steam.exe` 所在位置。
3. 将压缩包中的这三个 DLL 放到 Steam 根目录，并把整个 `dave-launcher` 文件夹放在它们旁边。文件夹内的 `DaveLauncher.exe`、`DaveLauncher.json` 和 `SteamPlayGate.js` 必须一起保留。不要将这三个 DLL 放进 Steam 的 `bin` 子目录。
4. 保留现有的 Lua、`opensteamtool` 配置目录和用户 TOML 配置。压缩包中的 `opensteamtool.example.toml` 只是示例，不需要覆盖现有配置。如果调整过 `DaveLauncher.json`，先备份，再将自己的配置合并到新版本。
5. 首次安装时，在 Steam 根目录创建名为 `.cef-enable-remote-debugging` 的空文件，已有则保留。重启 Steam 后等待库界面加载完成。
6. 打开“库 → 潜水员戴夫 → 属性 → 通用”，在“启动选项”中加入下面这一项，然后照常点击 Steam 的“开始游戏”。

```text
-offline
```

这是单横线、小写的独立参数。`--offline` 和 `-offline=no` 不会触发。其它已有启动参数可以保留；不要同时使用会重映射 AppID 的 `-onlinefix`。

第 5 步也可以在 PowerShell 执行，先把路径改成自己的 Steam 根目录：

```powershell
New-Item -ItemType File -Path (Join-Path '你的Steam目录' '.cef-enable-remote-debugging') -Force
```

该文件启用 Steam 库界面的本地控制接口，本功能要求它只监听 `127.0.0.1:8080`。这不是 Steam 的 `-console` 启动选项，也不需要修改登录文件。

压缩包还包含 `ost-Injector.exe`、自动注入任务脚本、配置示例和 `LICENSE`。已按上述方式安装时，无需为戴夫另外建立开机任务或快捷方式。详细说明见包内 `dave-launcher/README.zh.md`。

## 使用范围与退出方式

需要 Windows x64、.NET Framework 4.8、已安装的戴夫和可用的 Steam 登录缓存。戴夫的游戏文件及所需 DLC 内容应已准备好；本功能负责自动切换 Steam 的原生离线/在线流程，不会下载 DLC，也不修改服务端授权校验结果。

此流程会暂时让**整个 Steam 离线**。启动前应退出其它 Steam 应用。切换期间无需操作菜单，初始化完成后会自动上线。删除启动选项中的 `-offline` 即可恢复普通启动。

当前适配 AppID `1868140`。已有流程验证针对戴夫 `v1.0.6.2113.steam`、Steam Build ID `1788652215`，默认检查以下五个内容包：

```text
2677020, 2841140, 3543180, 4158580, 4394810
```

这五项是当前适配版本的检查范围，不代表商店全部商品或未来新增 DLC。其它游戏尚未适配，Steam 或戴夫更新后可能需要调整。

后台组件按本轮游戏日志中的 DLC 检查、原生离线回调和标题初始化事件判断进度；标题初始化后还有 10 秒保护时间。它不会只靠固定倒计时上线。若判断条件缺失或超时，而游戏仍在运行，会保持离线并记录原因。

需要主动恢复在线时，可在 PowerShell 执行，先改成自己的 Steam 路径：

```powershell
& '你的Steam目录\dave-launcher\DaveLauncher.exe' --online
```

该命令会立即请求恢复在线，不检查游戏是否初始化完成。运行记录位于 `dave-launcher` 下的 `last-run.json`、`last-error.txt` 和 `sessions` 文件夹。本功能不修改游戏存档或 Steam 登录配置。

## 版本说明

本版来自上游 `mmxlyo/OpenSteamTool` 的 `322d1d8` 基线，加上本仓库的戴夫启动适配与稳定性修正。它不包含当前 `main` 同步的全部上游更新，请勿将此适配版理解为最新上游整合版。

适配流程已有原始库按钮调用链验证，用户确认离线初始化后主菜单不再出现购买 DLC 提示。已有 170 项自动化检查覆盖 C# 编排、原生代码和 JavaScript 接入；本次发布的 Release 构建结果以对应 GitHub Actions 记录为准。
